# Glossary

**Annotation**
: What a data point means: a name, a description, a note, and whether it is personal
  information. One annotation can cover the same data point at several places. See
  [Annotating](annotating.md).

**Approval**
: Staff's decision on an upload that doesn't count yet: approved uploads count, rejected ones
  don't. See [Uploading](uploading.md#after-uploading).

**Changed**
: A data point earlier uploads had, where something about it (kind, type, format) is new in this
  upload. See [Reviewing](reviewing.md).

**Counts / counted upload**
: An upload that passed the checks or was approved: it is part of the platform's explorer and
  comparisons.

**Data point**
: A piece of information with a meaning of its own: a value, a list, an entry in a list, or a
  media file.

**DDP (data download package)**
: The data a platform gives you when you request it, often called a data takeout. Usually a ZIP
  archive of JSON, CSV or HTML files and media.

**Example**
: A sample value of a data point, shared publicly. See [Annotating](annotating.md#examples).

**Explorer**
: A platform's page showing everything collected about its DDPs as a tree. See
  [Exploring](exploring.md).

**Known**
: A data point earlier uploads had, unchanged.

**Matched**
: A data point that was probably moved or renamed from a known one.

**Missing**
: An annotated data point that an upload doesn't have.

**New**
: A data point no earlier upload had.

**PII (personally identifiable information)**
: Information that can identify a person, like an email address or a username. Annotations say
  whether a data point is PII.

**Representation**
: A concept described independently of any platform, like "the user watched a video", linked to
  the data points that hold it on each platform. See [Representations](representations.md).

**Request date**
: When the DDP was requested from the platform. Whether a data point is new, known or changed is
  worked out against the uploads requested earlier.

**Review**
: An upload's data points compared with what is known about the platform: new, known, changed,
  missing. See [Reviewing](reviewing.md).

**Structure**
: Which files and fields a DDP has and what type their values are, without the values. The only
  thing the DDP Tracker keeps of an upload.

**Suggestion**
: A change by someone who isn't staff, waiting for staff to accept or reject it. See
  [Annotating](annotating.md#suggestions).

**Vocabulary**
: The terms representations use: kinds of users, activities, things, and roles.
